# Corpus provenance

Every bundled project and organization is synthetic and authored for this reference implementation on 2026-10-28. No employer data, actual project outcomes, or third-party deployments are represented. The internal label simulates document visibility only. No real confidential content is bundled.

Natural text patterns and supported fields are documented in docs/data-contract.md. Uploaded PDF text is extracted locally using optional pypdf; scanned images require preprocessing outside this prototype. Uploaded content is not saved by the server.
